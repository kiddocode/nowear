La invitación dice "black tie" o "smart casual" y no tienes muy claro qué significa exactamente. No eres la única. El dress code de las bodas es uno de los temas que más dudas genera entre las invitadas.

## Black tie

Es el dress code más formal. Para las mujeres significa vestido largo de noche, telas nobles como el satén, el terciopelo o el chiffon, y complementos de joyería. Los colores oscuros son los más habituales aunque también se admiten colores vibrantes en tonos joya.

No es el momento para vestidos cortos ni para looks casuales por muy elegantes que sean.

## Cocktail o semi-formal

El más común en bodas españolas. Vestido midi o corto de tejido elegante, conjunto de falda y blusa sofisticado, o traje de chaqueta femenino. Es el dress code más versátil y el que más opciones permite.

Evita los tejidos informales como el algodón o el lino en esta categoría.

## Smart casual o informal

Más libertad pero con límites. Un vestido de día bonito, unos pantalones de traje con blusa elegante o un conjunto coordinado funcionan bien. Los vaqueros y las zapatillas siguen estando fuera de lugar aunque el dress code sea informal.

## Garden party o al aire libre

Colores claros, tejidos ligeros, flores. Los vestidos con estampados florales son perfectos para este formato. El calzado merece especial atención: los tacones de aguja se hunden en el césped, opta por tacones anchos o cuñas.

## Beach o destination wedding

Las bodas en la playa o en destinos cálidos tienen su propio lenguaje. Tejidos naturales como el lino o la seda, colores arena, coral o azul. Los vestidos fluidos funcionan mejor que los estructurados.

## Cuando no hay dress code indicado

Si la invitación no especifica nada, pregunta directamente a los novios o a alguien del entorno cercano. Es mucho mejor preguntar que adivinar.

Como referencia, si la boda es en una iglesia y luego en un restaurante o finca, el cocktail suele ser la opción más segura.

## El problema del look repetido independientemente del dress code

Sea cual sea el dress code, existe el riesgo de coincidir con otra invitada. Las bodas con dress code cocktail son las que más coincidencias generan porque todas compran en los mismos sitios con el mismo criterio de selección.
